# 가리고 — 드림즈 연구용 시제품

전문직 사무소의 AI 활용 전 식별정보 치환을 시험하는 브라우저 데모입니다.

## 실행

`index.html`을 브라우저로 열거나 GitHub Pages에서 접속합니다. 엑셀 라이브러리와 글꼴은 CDN에서 로드하므로 최초 접속에는 인터넷 연결이 필요합니다.

## 현재 기능과 한계

- 엑셀(.xlsx/.xls) 문자열 셀 및 붙여넣은 텍스트를 규칙 기반으로 처리합니다.
- 원문과 매핑표는 브라우저 메모리에만 유지합니다. 사용자 식별자, 사용 로그, 이메일을 수집하지 않습니다.
- 샘플 자료는 가상 데이터입니다. 먼저 샘플로 확인하세요.
- 이름 탐지는 한국어 NER 모델이 아니며, 누락·오탐이 발생할 수 있습니다.
- 엑셀 수식·메모·숨김 객체·문서 속성 등의 완전한 비식별화를 보장하지 않습니다. 원본 서식 보존에도 한계가 있습니다.
- 번호에 같은 마스킹 문자열을 쓰므로 개체 관계의 완전한 보존이나 역치환을 제공하지 않습니다.
- PDF/HWP 처리, 역치환, 이메일 신청 및 검증 지표 수집은 미구현입니다.
- 가명 처리 결과만으로 외부 AI 입력의 적법성 또는 안전성을 보장하지 않습니다.

## 배포

GitHub Pages에서 `main` 브랜치의 루트(`/`)를 게시합니다. 별도 빌드 단계는 없습니다.
