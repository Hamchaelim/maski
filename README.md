# 마스킷 — 드림즈 제품 컨셉 시연

현재 공개 페이지는 가상 자료만 사용하는 단계별 시연입니다.

- 노무·세무·법률의 미리 작성한 사례를 원본 → 가명 처리 → AI 초안 → 원문 복원 단계로 표시합니다.
- 고객 파일 선택, 업무 텍스트 입력, 다운로드, 결제, 실제 AI 연결은 제공하지 않습니다. 사전예약·기업 문의 버튼과 별도 연락처 폼을 제공합니다.
- 가명 처리와 복원은 예시 화면 전환이며 실제 문서 처리 기능이 아닙니다.
- 외부 CDN과 글꼴을 불러오지 않습니다. 신청·측정 연결은 Supabase 프로젝트에만 허용합니다. 고객 업무자료는 받지 않으며 신청 연락처와 이벤트는 별도 테이블에 저장합니다.
- 로컬 처리 제품의 실제 배포 방식, 지원 형식, 정확도와 보안은 추가 개발·검증이 필요합니다.

이전 파일 변환 시제품은 Git 이력과 사용하지 않는 자산에 남아 있지만 현재 index.html에서 불러오지 않습니다.

GitHub Pages: main 브랜치 루트 게시.

## 브랜드

서비스명: 마스킷(maskit). 사용자 제공 투명 PNG 로고는 assets/maskit-logo.png에 원본 그대로 포함했습니다. CSS로 표시 영역만 맞췄으며 원본 이미지를 변형하지 않았습니다. 남색 #172554, 민트 #65D6BC를 밝은 배경과 조합합니다. 기존 공유 링크를 유지하기 위해 저장소 이름은 변경하지 않았습니다.
