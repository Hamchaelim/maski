개인정보 수집·이용 및 측정 안내

마스킷 프로젝트 팀 드림즈는 사전예약·기업 도입 문의 응대와 솔루션 수요 검증을 위해 아래 정보를 처리합니다. 고객 업무자료·파일 원문은 받지 않습니다.

사전예약·기업 문의

필수 항목은 이름·이메일이며 기업 문의는 회사·사무소 이름과 회사 규모를 함께 받습니다. 전화번호와 직군은 선택 항목입니다. 필수 수집 동의를 거부하면 신청이 어렵지만 선택 항목을 입력하지 않아도 신청할 수 있습니다.

사전예약은 출시 및 초기 사용 기회 안내, 신청한 솔루션 검증 참여 관련 연락에 사용합니다. 기업 문의는 도입 검토 상담과 문의 응대에 사용합니다. 일반 광고성 마케팅 수신 동의로 사용하지 않습니다.

관심도 측정

무작위 브라우저 탭 세션 ID, 페이지 방문, 버튼 클릭 위치·종류, 폼 입력 시작, 제출 완료, 사용 흐름 단계와 유입 경로·캠페인 표지를 기록합니다. 이름·이메일·전화번호와 입력한 회사 정보는 클릭 이벤트에 넣지 않고 별도 신청 테이블에 저장합니다. 원본 문서, 입력 중인 필드 값, 전체 방문 URL이나 외부 페이지 주소는 측정 기록에 넣지 않습니다.

무작위 세션 ID는 브라우저 sessionStorage에 유지됩니다. 새로고침은 방문 횟수에 추가되지만 같은 탭의 세션은 합쳐질 수 있습니다. 세션 수는 실제 사람 수와 같지 않습니다. 브라우저 차단, 통신 실패, 반복 클릭 등에 따라 집계 오차가 있을 수 있습니다.

저장·접근 및 보유 기간

신청 정보와 측정 기록은 Supabase 서울 리전 프로젝트에 저장합니다. 공개 방문자의 테이블 조회는 허용하지 않으며, 팀 관리 계정에서만 확인합니다. 수집 후 6개월이 지난 기록은 일일 예약 작업으로 삭제합니다. 동의를 철회하거나 삭제를 요청하면 확인 후 필요한 조치를 진행합니다.

웹페이지는 GitHub Pages로 제공되며, 정적 페이지 제공·인프라 운영 과정에서 공급자의 정책에 따른 기술 로그가 발생할 수 있습니다. 이 페이지의 원문 처리 기능과 신청 연락처 저장은 서로 다른 목적입니다.
